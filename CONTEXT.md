# little by little

A private family archive: families keep memories of their children (photos, recordings, videos, words) and browse them by person, collection and colour.

## Language

### Pictures

**Picture**:
Any still image a family uploaded to be shown: a photo in a memory, a person's profile photo, or a pillar's cover.
_Avoid_: Image, photo (when meaning all three), stored picture

**Original**:
The file exactly as the family uploaded it. It is never altered, and is deleted only when nothing holds it any more.
_Avoid_: Master, source file

**Rendition**:
A resized copy of an Original made for display, at one of two sizes: THUMB for small tiles and portraits, DISPLAY for cards and full-screen viewing.
_Avoid_: Derivative (in conversation), thumbnail (when meaning either size)

**Holder**:
Something that shows a Picture: a memory's photo, a person's profile photo, or a pillar's cover. One Original can have several Holders at once.
_Avoid_: Owner, reference
